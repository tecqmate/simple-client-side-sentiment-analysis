# simple-client-side-sentiment-analysis

a) Data Fetching: To Allow the user to input or select a subreddit. Fetch the top 50 "Hot" posts of that chosen subreddit using the /r/{subreddit}/hot endpoint.

b) Sentiment Analysis: To Run a simple client-side sentiment analysis library on the titles of these 50 posts. Display the results clearly on the dashboard.
